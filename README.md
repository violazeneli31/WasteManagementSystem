# Waste Management System

Software Modeling & Design project – Group 10, Epoka University (Spring 2025).

The project models a waste management system (waste collection, recycling bins, and processing of the collected waste by material type) using requirements analysis and UML diagrams. It builds on our earlier Introduction to Software Engineering project.


## Repository contents

### Weekly meeting reports
'MeetingReport1.docx' - 'MeetingReport9.docx': one report per weekly team meeting (March – May 2025), recording the topics discussed, decisions made and tasks assigned.

### Full project
'WasteManagementSystemRequirementsSpecification.docx' and  'WasteManagementSystemRequirementsSpecification.pdf': the complete project document (same content in two formats). It contains:

- **Executive summary** and project overview
- **Product description**: context, user characteristics, assumptions, constraints and dependencies
- **Requirements**: functional and non-functional (usability, performance, availability, security, backup & recovery, supportability, organizational and external)
- **User scenarios / use cases**
- **Diagrams**
  - ER diagram
  - Use case diagram
  - Activity diagram
  - Class diagram
  - State diagram
  - Sequence diagram
  - Collaboration diagram
- **Design patterns**: Singleton, Observer, Decorator and Factory
- **Appendix**
